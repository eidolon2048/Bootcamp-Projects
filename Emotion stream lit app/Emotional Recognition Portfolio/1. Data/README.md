# Dataset Notes

The model was developed with the FER 2013 facial expression dataset.

Expected dataset structure for training notebooks:

```text
FER 2013 default/
  train/
    angry/
    disgust/
    fear/
    happy/
    neutral/
    sad/
    surprise/
  test/
    angry/
    disgust/
    fear/
    happy/
    neutral/
    sad/
    surprise/
```

The raw dataset is intentionally not copied into this project folder because it is large and should not be committed to GitHub.
