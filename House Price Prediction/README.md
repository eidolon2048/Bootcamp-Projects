# House Price Prediction

# In Process

Machine learning project using the Kaggle House Prices dataset for regression and classification tasks.

## Goal


## Dataset

The main dataset is the Kaggle House Prices: Advanced Regression Techniques dataset.

- `train.csv` - labelled training data with `SalePrice`
- `test.csv` - unlabelled Kaggle test data
- `data_description.txt` - feature documentation

## Approach

- Exploratory data analysis of housing features and sale prices
- Missing-value handling and feature preprocessing
- Regression modelling for `SalePrice`
- Classification target creation for expensive homes
- Model comparison using metrics such as accuracy, recall, F1-score, ROC-AUC, and PR-AUC
- Iterative notebook development across multiple modelling versions
