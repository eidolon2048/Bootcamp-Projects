# WBS Projects

Portfolio repository containing selected projects from the WBS Coding School. The projects cover machine learning, computer vision, business analytics, SQL analysis, Tableau dashboards, and data storytelling.

## Projects

### Emotional Recognition
Facial emotion recognition project using a DeepFace baseline, a custom CNN model, and a Streamlit app for image, video, and live camera emotion detection.

### Eniac Analysis
Business analysis project evaluating whether Magist should enter the Brazilian market through Eniac. Built with MySQL, Tableau, and presentation reporting.

### House Price Prediction
Machine learning project using the Kaggle Ames Housing dataset for classification and regression with advanced modelling techniques.

## Repository Structure

- `Emotional recognition/` - computer vision and Streamlit deployment project
- `Eniac analyse/` - SQL analysis, dashboard image, and final report
- `House Price Prediction/` - notebooks, datasets, and model iteration outputs
- `A:B test/` - currently empty / placeholder folder
