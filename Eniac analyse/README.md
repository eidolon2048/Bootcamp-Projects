# Eniac Analysis

Business analytics project evaluating whether Magist should enter the Brazilian market through a partnership with Eniac.

## Goal

The analysis investigates Magist's marketplace data to understand whether the platform is a good fit for selling tech products in Brazil. The recommendation is based on product demand, seller activity, revenue potential, and delivery performance.

## Tools

- MySQL for data analysis
- Tableau for dashboarding
- Google Slides / PDF for final presentation

## Key Questions

- Which tech product categories are sold on Magist?
- How large is the tech product market compared with total sales?
- Are expensive tech products popular?
- How many tech sellers are active on the platform?
- How much revenue do tech sellers generate?
- Are delivery times and late deliveries acceptable for Eniac's business model?

## Files

- `business_questions_final.sql` - SQL queries used for analysis
- `Eniac_Dashboard.JPG` - Tableau dashboard export
- `Eniac.pdf` - final presentation/report
- `LICENSE` - project license

## Outcome

The project combines SQL-based market analysis with a dashboard and final business recommendation for Magist and Eniac.
